# 미스터 월드 테마 여행 서비스

소프트웨어공학(71032) 프로젝트의 고객용 GUI 프로토타입입니다. 테마(허니문·효도·골프·트레킹)와 투어 등급을 고르고, 호텔·식사·교통을 바꿔 예약할 수 있습니다.

- 실행: `index.html`을 브라우저로 열기 (서버 불필요)
- 데모 계정: `demo` / `1234`

## 추가 구현 필요

- **음성 인식:** 음성으로 여행 상품 선택 (고객 인터페이스 2단계)
- **직원용 GUI:** 여행 상품 기획, 창고 물품 관리
- **서버:** 회원·예약 데이터 저장, 실제 문자 발송 (현재는 브라우저에만 저장)
